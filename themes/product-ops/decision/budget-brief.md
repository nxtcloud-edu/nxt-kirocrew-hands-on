# 4분기 캠페인 예산 배분 브리프

| | |
|---|---|
| 결정 사항 | 검색광고 · SNS · 오프라인 세 채널의 4분기 예산 배분안 |
| 결정 주체 | 기획 리뷰 회의 (배분안 상정: 담당 기획자) |
| 마감 | 9월 첫 주 경영 보고에 포함 |

## 배경

- 연간 마케팅 예산 12억 중 3분기까지 8.1억 집행. **4분기 가용 총예산 3억**
- 연간 목표 대비 진척: 매출 기여 목표의 71% 달성 (계획 75% 대비 소폭 미달), 신규 고객 유입 목표의 64% 달성 — **신규 유입이 더 급하다**
- 3분기 배분은 검색 1.2억 / SNS 0.9억 / 오프라인 0.6억이었다

## 배분 기준 (연간 마케팅 계획 기준)

1. ROAS 300% 이상 채널에 우선 배분한다
2. 분기 신규 고객 유입 비중 30% 이상을 유지한다
3. 단일 채널 배분이 총예산의 60%를 넘지 않는다 (채널 리스크 분산)

채널당 최소 배분 조항은 없다 — 단, 개별 계약 조항은 별도 확인 (운영 검토 보고 참조).

## 판단에 쓸 자료

- `channel-performance.json` — 채널별 월별 성과 실측
- `marketing-ops-report.md` — 계약·운영 제약
- 필요 시 `../voc/` — 고객 반응 참고

## 참고

- 경영 보고는 세 기준의 충족 여부를 채널별로 각각 명시해야 한다
- 기준과 실측이 어긋나는 배분안(예: 기준 미달 채널에 배분 유지)은 근거를 명시해 기획 리뷰 회의에 상정한다 — 회의의 결정 사항이다
- 보고 이후의 배분 변경은 다음 분기 시작 전까지 1회만 가능하다
