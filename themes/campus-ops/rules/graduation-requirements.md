# NXT대학교 졸업 요건 안내

| | |
|---|---|
| 발췌 범위 | 총 이수 학점, 전공·교양 배분, 졸업 프로젝트, 외국어 요건 |
| 기준 학년도 | 2026학년도 재학생 기준 |
| 담당 부서 | 학사지원팀 |

## 1. 총 이수 학점

| 구분 | 학점 |
|---|---|
| 전공 필수 | 45 |
| 전공 선택 | 30 |
| 교양 필수 | 21 |
| 교양 선택 | 15 |
| 자유 선택 | 19 |
| 총 이수 학점 | 130 |

## 2. 전공·교양 배분

- 전공 학점은 전공 필수와 전공 선택을 합쳐 최소 75학점 이상 이수해야 한다.
- 교양 필수는 글쓰기, 소프트웨어 기초, 진로 설계 등 지정 교과목으로 구성되며 학년별 이수 순서를 권장한다.
- 전공 트랙(데이터·응용소프트웨어·시스템) 선택은 2학년 이상 재학생이 신청하며, 트랙별 필수 과목은 학과 안내를 따른다.
- 복수전공·부전공 이수자는 별도 학점 기준이 적용되며 학과 사무실에서 개별 확인한다.

## 3. 졸업 프로젝트

4학년 재학생은 졸업 프로젝트(팀 단위)를 필수로 이수해야 한다. 지도교수 배정 후 한 학기 동안 진행하며, 학기 말 발표회에서 결과물을 공개 평가받는다.

## 4. 외국어 요건

졸업 사정 신청 전까지 공인 어학 성적(토익 등)을 학과 기준 점수 이상으로 제출해야 한다. 기준 점수는 매 학년도 학사지원팀 공지로 확정한다.

## 5. 졸업 사정 절차

① 졸업 사정은 매 학기 말 이수 학점과 외국어 요건 충족 여부를 확인해 진행한다.
② 요건을 충족하지 못한 학생은 다음 학기로 사정이 유예된다.
③ 매 학기 초 학사지원팀이 졸업요건 안내 특강을 열어 학년별 상담을 진행한다.
