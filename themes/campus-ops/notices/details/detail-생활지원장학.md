# 2026학년도 2학기 생활지원장학 추가 신청 안내

| | |
|---|---|
| 문서번호 | 장학-2026-0207 |
| 게시일 | 2026-09-05 |
| 게시 부서 | 장학복지팀 |
| 관련 규정 | 장학 규정 제4조 (생활지원장학) |

## 1. 목적

학기 초 정규 신청 기간에 소득분위 산정이 늦어져 신청하지 못한 재학생을 대상으로 추가 접수를 받는다.

## 2. 대상

- 2026학년도 2학기 등록을 마친 재학생
- 한국장학재단 소득분위 산정 결과가 기준 구간 이하인 자
- 정규 신청 기간에 신청하지 않았거나, 신청 후 소득분위가 정정된 자

## 3. 신청 기간 및 방법

- 접수 기간: 2026년 9월 7일 ~ 9월 22일 화요일 17:00
- 접수 경로: 학생지원처 포털 장학 메뉴에서 온라인 신청서 작성 후 서류 첨부
- 온라인 제출이 어려운 경우 본관 2층 장학복지팀 창구에서 방문 접수한다

## 4. 제출 서류

| 서류 | 비고 |
|---|---|
| 생활지원장학 신청서 | 포털 양식 사용, 자필 서명 스캔본 첨부 |
| 소득분위 산정 결과 화면 | 한국장학재단 시스템 출력본, 3개월 이내 |
| 주민등록등본 | 1개월 이내 발급분, 주민등록번호 뒷자리 가림 |
| 가족관계증명서 | 세대 분리된 경우에만 제출 |
| 본인 명의 통장 사본 | 환급 발생 시 입금 계좌로 사용 |

서류가 하나라도 누락되면 심사 대상에서 제외되며 접수 기간 종료 후에는 보완 제출을 받지 않는다.

## 5. 심사 일정

| 단계 | 기간 |
|---|---|
| 서류 접수 | 09-07 ~ 09-22 |
| 서류 검토 및 자격 확인 | 09-23 ~ 10-02 |
| 선발 심의 | 10-05 ~ 10-08 |
| 결과 발표 | 10-13, 포털 개별 조회 |
| 지급 처리 | 10월 말 등록금 상계 또는 계좌 환급 |

## 6. 유의사항

- 선발은 소득분위가 낮은 순으로 예산 범위 내에서 이루어지며, 신청자 전원이 선발되는 것은 아니다.
- 제출한 소득분위 자료는 재단 시스템과 대조해 확인한다. 확인 결과가 제출 서류와 다르면 접수를 무효로 처리한다.
- 허위 자료 제출이 확인되면 지급된 장학금을 회수하고 이후 신청 자격을 제한한다.
- 학기 중 휴학하거나 자퇴하면 지급이 중단되며 이미 지급된 금액은 학적 변동일 기준으로 정산한다.

## 7. 문의

장학복지팀 (본관 2층 장학창구) · 평일 09:00~17:00
소득분위 산정 자체에 관한 문의는 한국장학재단 상담 창구로 문의해야 한다.
