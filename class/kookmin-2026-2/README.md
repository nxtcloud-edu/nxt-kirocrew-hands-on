## 자료 추가 규칙

- 새 주차는 `week03/`, `week04/`처럼 두 자리 주차 번호로 추가합니다.
- 각 주차에는 `README.md`, 강의 PPT·PDF, 실습 안내와 필요한 양식을 둡니다.
- 수업에 사용할 입력은 해당 주차의 `data/`에 포함합니다. 기본 교재에서 가져온 자료도 주차별 사본으로 고정하고 출처를 기록합니다.
- 학생별 결과물은 각자 받은 주차 폴더의 `results/`에 보관하고 Git 추적에서 제외합니다.
- 화면과 배포용 안내에는 고정 시간 배분을 표시하지 않습니다. 강사용 참고 시간은 PPT 발표자 메모에 둡니다.
