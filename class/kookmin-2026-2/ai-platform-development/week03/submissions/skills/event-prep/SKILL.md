# event-prep 스킬

행사 참가신청 데이터를 규칙대로 집계해 준비 목록을 정리하는 스킬이다.
숫자 집계는 사람이 세면 실수가 나므로 Python이 담당하고, AI는 결과를 읽어 준비할 일을 정리한다.

## 언제 사용하나

- `참가신청.csv`(신청 명단)와 `행사안내.md`(집계 규칙)가 주어졌을 때
- 신청이 변경되어 인원·간식 수량을 다시 세야 할 때

## 입력 자료

- `참가신청.csv` : 신청번호, 이름, 학년, 참가 여부, 간식 선택
- `행사안내.md`  : 집계 규칙(정원, 참가/불참 처리, 간식·생수 기준, 미응답 처리)

## 집계 규칙 (행사안내.md 기준)

1. **참가 인원**: `참가 여부`가 `참가`인 사람만 센다.
2. **불참 제외**: `불참`인 사람은 간식을 선택했더라도 주문에서 제외한다.
3. **간식 주문**: 참가자가 고른 `샌드위치`/`주먹밥`을 1인 1개씩 센다. `받지 않음`은 주문하지 않는다.
4. **미응답**: 참가자인데 간식 선택이 빈칸이면 임의로 정하지 말고 "확인할 사람"으로 따로 모은다. **불참자의 빈칸은 무시**한다.
5. **생수**: 간식과 무관하게 참가 인원수만큼 준비한다.
6. **정원**: 정원(12명)을 넘으면 초과로 표시해 알린다.
7. 주문 "확정"과 실제 "주문 완료"는 다른 상태다. 이 스킬은 확정 수량만 계산한다.

## 실행 절차

1. Python 버전 확인: `python --version` (3.x)
2. 스크립트 실행:
   ```
   python scripts/aggregate.py <참가신청.csv 경로> <행사안내.md 경로 또는 정원> [결과.json 경로]
   ```
   - 예: `python scripts/aggregate.py ../../mission/참가신청.csv 12 ../result.json`
3. 저장된 JSON을 열어 사람이 직접 대조한다.
   - 특히 미응답자 명단과 간식 합계가 참가 인원과 맞는지 확인한다.
4. 신청이 바뀌면 CSV만 고치고 같은 명령을 다시 실행한다.

## 결과 JSON 구조 (항상 동일)

```json
{
  "정원": 12,
  "참가_인원": 0,
  "정원_초과": false,
  "간식_주문": { "샌드위치": 0, "주먹밥": 0, "받지_않음": 0 },
  "생수": 0,
  "미응답_확인_필요": [ { "신청번호": "", "이름": "" } ],
  "불참": [ { "신청번호": "", "이름": "" } ],
  "준비할_일": [ "" ]
}
```

## 사람이 확인할 부분

- 미응답 명단이 실제 CSV의 빈칸 참가자와 일치하는가
- 간식 합계(샌드위치+주먹밥+받지않음)가 참가 인원과 맞는가
- 정원 초과 표시가 맞는가
