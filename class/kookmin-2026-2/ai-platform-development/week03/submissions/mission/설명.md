# 설명

## 1. 에이전트·스킬 이름

- 에이전트: **Kiro (KiroCrew)**
- 스킬: **event-to-json** — 참가신청 CSV와 행사안내문을 읽어 참가 인원·간식·생수를 규칙대로 집계해 JSON으로 정리 (스크립트: `aggregate.py`)

## 2. 정리 기준

- 참가 여부가 **참가**인 사람만 인원에 포함 (불참 제외).
- 간식은 참가자만, 1인당 1개. **받지 않음**과 **빈칸**은 주문 수량에서 제외.
- 간식이 빈칸인 **참가자**는 미응답으로 따로 정리(임의로 메뉴 채우지 않음). 불참자 빈칸은 무시.
- 생수는 간식과 무관하게 **참가 인원수만큼**.
- 집계 = 주문 확정용 수치일 뿐, 실제 주문·예약과는 구분.

## 3. 테스트 후 수정한 점

- A06(윤민재)을 불참→참가로 바꾼 CSV로 다시 실행 → 참가 인원·샌드위치·생수가 각각 **+1**(10→11, 4→5, 10→11), 미응답(A07)은 변화 없음을 확인.
- CSV를 `utf-8-sig`로 읽도록 하여 Excel 저장 시 붙는 BOM에도 한글이 깨지지 않게 수정.
- "받지 않음"의 가운데 공백을 원문 그대로 매칭하도록 하고, 값 앞뒤 공백은 제거해 오탈자·공백으로 인한 누락을 방지.
