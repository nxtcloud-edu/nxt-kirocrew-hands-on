가능한 운영안

  • 기본안 — 140명(확정) 운영: 승인 정원 160명 이내로 안전. 회비 충분. 학교지원금은 6,000원 부족 → 지원금 소액 부족분을 회비 전용 또는 지원 적격 항목 재조정으로 해소 검토(ACCOUNT-01 제4조 사용목적·증빙 대조). 현재 근거로 즉시 실행 가능한 안.
  • 확대안 — 160명(승인정원)까지: 대기자 전환으로 최대 160명. 지원금 34,000원 부족 → 부족분 재원 대책 필요. 대기자 전환은 승인정원·물품·재원 확인 후 신청 순서대로(CLUB-01 제3조).
  • 확대안 — 180명(홍보정원): 정원 변경 미승인(MEMO-04)이라 현재 실행 불가. 장소 정원 160→180 변경 승인 + 지원금 62,000원 부족분 대책이 선행되어야 함.

추가 확인 사항

  • 정원 변경 승인: 180명은 요청 예정 단계, 승인 기록 없음(MEMO-04) → 승인 여부 확인 필요.
  • 외부인 참가 조건: MEMO-04에서 "결정하지 않았다" → 미결정. 다른 문서에도 근거 없음 → 확인 필요.
  • 기념품 재원: 학교지원금은 기념품·개인선물 제외(APPROVAL-FUND-04 · RULE-01). 회비 기념품은 1인 3,000원 이내·결재·영수증 필요(CLUB-01 제2조) → 기념스티커(P04) 지출 요건 확인.
  • 인화비 용도 미기재분: 영수증·사용 목적 재확인 필요(MEMO-04).
  • 지원금 부족분: 전 시나리오에서 지원금 부족. 잔여 500,000원은 정산 승인 후 지급이라 현재 가용현금 아님(APPROVAL-FUND-04) → 부족분 재원 계획 필요.
