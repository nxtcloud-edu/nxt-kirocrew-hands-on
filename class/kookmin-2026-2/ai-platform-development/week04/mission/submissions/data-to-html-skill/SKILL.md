# data-to-html

여러 개의 MD 문서와 CSV를 입력받아, **문서 요약 + CSV 핵심 표**를 담은 하나의
HTML 리포트를 만든다. MD 문서 판독·요약은 AI가 하고(판단), 요약 검증과 CSV
파싱·HTML 조립은 파이썬 스크립트가 한다(결정적 처리).

## When to use

- "이 문서들 요약해서 표랑 같이 HTML로 만들어줘"
- 여러 MD 문서와 데이터 CSV가 있고, 한 장짜리 리포트로 정리해야 할 때.
- 문서/CSV가 바뀌면 같은 절차로 다시 생성한다.

## 입력 / 출력

- **입력**: 여러 개의 MD 문서(요약 대상) + CSV 1개(핵심 표로 렌더할 데이터).
- **출력**: `제목 / 문서 요약 목록 / CSV 표`를 담은 단일 HTML 파일.

## 역할 분담

- **AI(판단)**: MD 문서를 읽고 각 문서를 한두 문장으로 요약한다. 리포트 제목을
  정한다. 결과를 아래 **요약 JSON 스키마**로 만든다. 추측이 필요한 부분은
  요약에 넣지 말고 사용자에게 확인한다.
- **스크립트(결정적)**: `scripts/build_html.py` 가 요약 JSON을 스키마로 검증하고,
  CSV를 그대로 파싱해 표로 만들고, 둘을 합쳐 HTML을 조립한다. 스키마가 맞지
  않으면 저장하지 않고 사유를 알린다.

## 요약 JSON 스키마 (고정)

```json
{
  "제목": "리포트 제목",
  "문서_요약": [
    {"문서명": "행사안내.md", "요약": "정원 12명, 참가자 기준 간식/생수 준비 규칙."},
    {"문서명": "공지.md",   "요약": "행사일 2026-09-28, 장소 변경 안내."}
  ]
}
```

| 키 | 자료형 |
|---|---|
| `제목` | 비어있지 않은 문자열 |
| `문서_요약` | 1개 이상 항목의 목록 |
| `문서_요약[].문서명` | 비어있지 않은 문자열 |
| `문서_요약[].요약` | 비어있지 않은 문자열 |

최상위 키 누락·추가, 자료형 오류, 빈 값이면 스크립트가 저장을 거부한다(종료 코드 1).

## 실행 절차

1. AI가 MD 문서들을 읽고 위 스키마의 요약 JSON을 만들어 파일(예: `summary.json`)로
   저장한다.
2. 이 `SKILL.md`가 있는 폴더의 `scripts/`로 이동해 조립 스크립트를 실행한다.

   ```bash
   cd scripts
   python build_html.py --summary summary.json --csv data.csv --out report.html
   # 표시 행 제한(예: 앞 20행)
   python build_html.py --summary summary.json --csv data.csv --out report.html --max-rows 20
   # 요약을 표준입력으로 전달
   echo '<json>' | python build_html.py --summary - --csv data.csv --out report.html
   ```

   Windows에서 `python`이 없으면 `py -3`을 쓴다.

3. 검증 통과(종료 코드 0)면 지정 경로에 HTML이 저장된다. 실패(종료 코드 1)면
   사유가 표준오류로 나오고 파일은 저장되지 않는다 — 요약 JSON을 고쳐 다시 실행한다.
4. 저장된 HTML을 사용자에게 전달한다(브라우저로 열어 미리보기 가능).

## Gotchas

- CSV/JSON은 `utf-8-sig`로 읽어 Excel 저장 BOM도 처리한다. 한글 깨짐 주의.
- CSV의 첫 행은 헤더로 취급한다. 완전히 빈 행은 건너뛴다.
- HTML 값은 모두 이스케이프한다(`<`, `>`, `&`, 따옴표) — CSV/요약에 태그 문자가
  있어도 안전하다.
- `--max-rows`로 표를 줄이면 리포트에 "전체 N행 중 일부" 안내가 붙는다.
- 요약은 AI의 판단이므로, 확정 정보와 추정을 섞지 않는다. 애매하면 확인 먼저.
