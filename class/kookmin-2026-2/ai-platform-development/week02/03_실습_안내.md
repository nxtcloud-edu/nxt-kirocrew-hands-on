# 03 · 첫 업무: 수업 공지·과제 관리

## 1. 크루 준비

| 항목 | 설정 |
|---|---|
| 이름 | `campus-helper` |
| TRIGGERS | 수업 공지, 과제 점검, 진로 준비 |
| 템플릿 | `kirocrew` |
| Workspace / Memory store | 새 Workspace / `default` |
| 세션 프로젝트 | Clone한 저장소 최상위 폴더 |

## 2. 먼저 직접 읽기

Kiro IDE에서 `data/course/notices.md`, `my-tasks.md`를 열고 **변경된 마감·확인할 질문** 찾기.
가상 자료 기준: **2026-09-09 09:00 KST**. 현재 날짜로 바꾸지 않기.

## 3. 첫 지시

```text
기준 폴더: class/kookmin-2026-2/ai-platform-development/week02/
data/course/notices.md와 my-tasks.md를 읽어 줘.
자료 기준 시각으로 과제별 마감·제출 조건·준비 상태를 대조해 줘.
할 일과 확인 질문을 공지 ID 근거와 함께 보고해 줘.
모르는 것은 추측하지 말고, 아직 파일은 수정하지 마.
```

첫 보고는 대화에서 확인합니다. 아직 파일에 옮기지 않습니다.

## 4. 검증 → 보완 → 저장

- 변경 공지의 적용 범위가 맞는가?
- 날짜만 있는 마감에 시각을 지어내지 않았는가?
- 준비 완료와 제출 완료를 구분했는가?
- 공지 ID 한 건을 직접 대조하고 기준 하나 보완.

검증한 보고를 바탕으로 AI에게 요청합니다.

```text
기준 폴더: class/kookmin-2026-2/ai-platform-development/week02/
검증한 과제 내용을 submissions/work.md의 "할 일"에 정리해 줘.
과제별 마감과 다음 행동을 불렛으로 적어 줘.
"내 일정·조건"과 입력 원본은 수정하지 마.
실제 제출·일정 등록은 하지 마.
```

Kiro IDE에서 `work.md`를 열고 **내 일정·조건**에 직접 한두 줄 작성합니다.
예: “수요일 저녁에는 작업할 수 없음”, “자료 확인은 목요일 오전에 할 예정”.
공개 가능한 연습용 조건을 적어도 됩니다. 이후 AI가 이 항목을 보존하는지 확인합니다.

이어서 [05 작업 이어가기](05_작업_이어가기.md).

**선택 확장:** `data/career/`의 공고·프로필로 지원 준비 점검. 필수/우대·미기재/미충족 구분. 결과는 대화에서 확인하며 추가 제출 파일 작성이나 실제 지원은 하지 않음.
