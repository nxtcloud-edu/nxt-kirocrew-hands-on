# 개인 작업과 제출

이 폴더에는 빈 양식이 미리 들어 있습니다. 자기 Public 포크에서 항목을 채우고 Commit·Push합니다. 완성된 답안은 제공하지 않습니다.

| 파일 | 작성할 내용 |
|---|---|
| start.md | AI로 줄이고 싶은 일 · 수업에서 확인할 질문 |
| course-first.md | 첫 지시와 최초 보고 |
| course-check.md | 원문 근거와 대조한 검증 결과 |
| execution-record.md | 실행·검증·수정 이유·커밋 링크 |
| workspace/task-plan.md | 준비 계획과 새 공지 반영 |
| workspace/my-notes.md | 사람이 작성한 계획 · AI 수정 제외 |
| context/decision-rules.md | 판단 기준과 이유 |
| context/work-state.md | 완료·미해결·다음 행동·참고 경로 |
| transfer-plan.md | 자신의 실제 업무에 적용할 설계 |

## 첫 변경과 Push

1. Kiro IDE에서 `start.md`를 열고 자신의 관심사와 질문을 채웁니다.
2. 저장 후 `git status`에서 수정된 파일을 확인합니다.
3. Commit으로 변경을 기록하고 자기 `origin`에 Push합니다.
4. GitHub의 자기 포크에서 파일 내용과 커밋을 확인합니다.

명령어는 [GitHub 준비와 제출](../01_GitHub_준비와_제출.md)을 따릅니다.
이후 첫 작업 → 새 공지 반영 → 새 세션 재개를 [작업 이어가기](../05_작업_이어가기.md)에 따라 기록합니다. 이미 채운 내용을 빈 양식으로 덮어쓰지 않습니다.

채용 공고는 선택 확장입니다. 진행하는 경우 `career-first.md`, `career-check.md`를 추가하며 필수 제출에는 포함하지 않습니다.

## 제출

- 자기 Public 포크 URL + 최종 커밋 링크를 수업 채널에 제출
- nxtcloud-edu는 자료 수신용 upstream, 결과 Push는 자기 origin
- 강사 원본에 Push·Pull Request하지 않음
- 공개 파일에 실명·학번·인증 정보를 적을 필요 없음
