# 개인 작업과 제출
강사 원본은 자료 수신용, 이 폴더는 자기 포크에서만 수정합니다.

```text
submissions/
├── course-first.md          # 첫 보고 보관
├── course-check.md          # 초기 검증 보고
├── execution-record.md      # 지시·검증·수정 이유·커밋 링크
├── workspace/
│   ├── task-plan.md         # 변경 공지를 반영할 계획
│   └── my-notes.md          # 사람이 쓴 메모, AI 수정 제외
└── context/
    ├── decision-rules.md    # 판단 기준과 이유
    └── work-state.md        # 진행 상태와 다음 행동
```

파일은 학생이 실습 중 생성합니다. 첫 작업 → 갱신 → 새 세션 재개의 변화를 커밋으로 남깁니다. 상세 절차는 [작업 이어가기](../05_작업_이어가기.md).
채용 공고 점검의 career-first.md / career-check.md는 선택 확장 결과입니다.
제출은 자신의 GitHub 포크 URL과 최종 커밋 링크. 강사 원본에 PR하지 않습니다.

- `transfer-plan.md`: 내 업무의 입력·단계·결과·경계·검증·이어갈 맥락. 구현이 아닌 적용 설계와 이유를 기록합니다.

학생 포크는 Public으로 유지합니다. 수업 채널에서 본인과 포크 URL·최종 커밋 링크를 매칭하여 제출합니다. 작성자 표시 이름이 실명일 필요는 없습니다.

## 첫 저장 연습
Crew에서 작업하기 전에 이 폴더에 `start.md`를 직접 작성합니다. AI로 줄이고 싶은 일과 수업에서 확인할 질문을 적고 Commit·Push한 뒤 내 GitHub에서 확인합니다.
