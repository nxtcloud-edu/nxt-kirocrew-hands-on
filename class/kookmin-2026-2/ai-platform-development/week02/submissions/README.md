# 2주차 개인 제출물

학생 본인의 포크에서 아래 파일을 작성하고 커밋·푸시합니다. 이 README는 강사 안내이며 그대로 유지합니다.

- `daily-check.md`: 주문 점검 최종 보고서
- `club-check.md`: 동아리 지원서 점검 최종 보고서
- `execution-record.md`: 첫 지시·첫 결과·수정 이유·재검증·짝 비교 기록

상위 폴더의 실행 기록 양식을 `execution-record.md`로 복사해 작성합니다. 자료 원본은 수정하지 않고, 이미 있는 결과는 보존하거나 변경 이력을 남깁니다. 인증정보·개인정보는 제출하지 않습니다.
