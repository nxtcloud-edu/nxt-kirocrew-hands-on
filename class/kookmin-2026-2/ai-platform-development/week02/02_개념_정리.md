# 2주차 개념 정리

버튼 조작을 다른 업무에도 적용하기 위해 짚는 개념입니다.

## 같은 입력, 다른 결과

- 표현과 판단의 변동
- 같은 원문·같은 검증 기준
- 한 번 성공과 반복 신뢰

## 에이전트를 만든다는 것

- 모델 · 판단의 엔진
- 도구 · 실제 수행 수단
- 컨텍스트 · 지시와 자료
- 호출 조건 · 언제 일할까

## 이름을 붙이면 전문가가 될까?

- 역할 이름과 실제 능력
- 템플릿의 도구·지시
- 판단에 필요한 업무 자료
- 트리거와 설명의 구분

## 담당자와 작업 자료는 별개

- 크루에 묶인 워크스페이스
- 세션에 연결한 프로젝트
- 전환 뒤 경로 재확인

## 지시가 실행으로 이어지는 과정

- 허용된 도구 안에서 선택
- 실행 결과로 다음 행동
- 완료 또는 사람에게 확인

## 사실과 해석을 나눠 읽기

- 도구가 반환한 원문
- 모델이 계산·해석한 보고
- 확정과 확인 필요 구분

## 만들고, 관찰하고, 고치기

- 누락된 기준 찾기
- 지시 한 가지 보완
- 같은 원문으로 재검증

## 판단하는 모델, 허용하는 시스템

- 모델의 도구 실행 요청
- 런타임의 권한 확인
- 사람의 경로·변경 검토
- 읽기도 범위 확인

## 다른 업무에도 같은 구조

- 입력 문서와 판단 기준
- 보고 형식과 완료 조건
- 사람이 결정할 경계

## 기본 교재

- [과정 개요](https://workshop.nxtcloud.kr/courses/kiro-crew/00-overview)

Crew의 설정 항목과 일반 개념은 구분합니다. 모델·도구·컨텍스트·호출 조건은 설명의 관점이고, 템플릿·워크스페이스·메모리·트리거는 제품에서 그 조건을 구성하는 항목입니다. 모델의 실행 요청과 런타임의 권한 통제도 별개입니다.

## 입력 자료 출처

이 저장소의 기본 교재 자료를 2주차 수업용 사본으로 고정했습니다.

- 공통 실습: `data/course/notices.md`, `data/course/my-tasks.md`
- 직접 도전: `data/career/job-postings.md`, `data/career/my-profile.md`

입력은 이 주차 폴더 기준입니다. 모두 가상 자료이며 기준 시각은 2026-09-09 09:00 KST입니다. 실제 서비스 조회·제출·지원은 하지 않습니다.

## AI와 작업을 이어가는 세 가지 기록
- Git: 무엇을 어떻게 바꿨는지 기록.
- 판단 기준: 사람이 아는 조건과 이유를 명시.
- 작업 상태: 완료·미해결·다음 행동을 전달.

파일로 저장해도 자동으로 모든 맥락이 적용되지는 않습니다. 새 세션에서 파일을 읽도록 지시하고 재개 결과를 검증합니다.
