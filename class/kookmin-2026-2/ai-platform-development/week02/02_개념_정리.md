# 02 · 핵심 개념

| 개념 | 이번 실습에서 볼 것 |
|---|---|
| 모델 | 자료 해석·다음 행동 판단 |
| 도구 | 파일 읽기·수정 등 실제 실행 |
| 컨텍스트 | 지시·입력 자료·판단 기준·작업 상태 |
| 실행 경계 | 허용된 경로·수정 범위·사람의 승인 |
| 검증 | 보고 내용을 원문 근거와 대조 |

**지시 → 자료 읽기 → 판단 → 도구 실행 → 결과 확인 → 보완**

- 역할 이름만으로 전문가가 되지 않음. 업무 자료와 기준 필요.
- 모델의 실행 요청과 시스템의 권한 통제는 별개.
- 크루의 워크스페이스와 세션의 프로젝트 경로는 별개. 연결 확인.
- 같은 입력도 결과가 달라질 수 있음. 한 번의 성공보다 반복 검증.
