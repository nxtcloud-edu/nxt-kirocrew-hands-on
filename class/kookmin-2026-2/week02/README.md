## 폴더 구성

```text
week02/
├── README.md
├── 국민대_AI플랫폼개발_W02.pptx
├── 국민대_AI플랫폼개발_W02.pdf
├── 실습_안내.md
├── 개념_정리.md
├── 실행_기록_양식.md
├── data/
│   ├── store/  # 주문·재고 공통 실습
│   └── clubs/  # 모집 요강·지원 명단 직접 도전
└── results/    # 각자 실행 결과, 개인 파일은 Git 추적 제외
```

IDE와 Crew 프로젝트는 **SETUP.md와 class가 있는 저장소 최상위 폴더**로 연결합니다. 수업용 입력은 이 주차의 `data/`에 모두 포함되어 있으며 기본 Lab 폴더에 의존하지 않습니다.

- [설치 안내](../../../SETUP.md)
- [오늘의 주문](data/store/orders-today.md) · [재고](data/store/inventory-status.md)
- [모집 요강](data/clubs/recruit-notice.md) · [지원 명단](data/clubs/applicants.md)
- [결과 저장 안내](results/README.md)

교재 캡처는 화면 설명용입니다. 캡처의 예전 경로 대신 PPT 지시문과 실습 안내에 적힌 `class/kookmin-2026-2/week02/` 경로를 사용합니다. 입력 원본은 보존하고 결과는 `results/`에 저장합니다.
